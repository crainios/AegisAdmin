# Politique de sécurité

La série 0.2.x est une version candidate. Les correctifs sont appliqués à la
dernière version publiée dans le dépôt APT officiel.

N’ouvrez pas d’issue publique pour une vulnérabilité réelle ou suspectée.
Utilisez **Report a vulnerability** dans l’onglet Security du dépôt GitHub.
Indiquez la version, le système, le composant, les conditions de reproduction
et l’impact estimé, sans transmettre de mot de passe, clé privée, secret TOTP,
cookie, sauvegarde réelle ou journal contenant des données personnelles.

Évaluez d’abord AegisAdmin sur une machine restaurable avec un accès SSH
indépendant. Utilisez uniquement les paquets signés provenant de
`https://packages.aegisadmin.fr` et ne désactivez jamais les contrôles APT.
