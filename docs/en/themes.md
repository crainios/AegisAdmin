# Themes

[Version française](../themes.md)

AegisAdmin provides Dark, Light, Bootstrap and Neon Pop themes. A user's choice
is stored in their SQLite profile and restored at login; the browser cookie
provides immediate rendering but is not the authoritative storage.

Themes share the same components, responsive behavior and permission rules.
Decorative styling must preserve readable contrast and must not introduce
permanent animation into an administration interface.
